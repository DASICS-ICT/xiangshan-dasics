## Documentation README Sync Rule

When changing documentation in either of these sibling documentation repositories:

- `doc-xiangshan`
- `../NEMU/doc-nemu`

always check whether that repository's `README.md` still matches the updated content, navigation, filenames, terminology, and remote repository name.

If the README becomes stale, update it in the same change and verify that links point to existing files.

For `doc-xiangshan`, pay special attention to:

- `treg-zero-design-log/`
- `sreg-crypto-design-log/`
- `paper-writing/`
- `xiangshan/`

For `doc-nemu`, pay special attention to:

- `dasics/`
- `reg-protection/treg-zero/`
